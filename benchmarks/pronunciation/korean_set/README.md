## 1. 목표 규모와 구성

- **화자:** 한국어가 모국어인 성인(만 19세 이상) 20명 이상. 만 14세 미만은 법정대리인 동의가 필요하므로 1차 수집에서 제외합니다. (speechocean762는 절반이 어린이지만, 이 앱의 대상은 성인 학습자입니다.)
- **수준 분포:** 자기 평가 수준(매니페스트 `self_rated_level` 1~5) 기준으로 낮음(1~2)·중간(3)·높음(4~5)에 각각 5명 이상.
- **발화:** 화자당 20개, 총 400개 이상.
  - 스크립트 읽기 15개: 공통 문장 목록(아래 §2)에서.
  - 자유 발화 5개: 질문에 20~40초로 답하기. 기준 문장은 사람이 확인한 전사입니다(§4 1단계).
- **녹음 장치:** 절반 이상은 노트북 내장 마이크(앱의 실제 사용 환경), 나머지는 헤드셋. 장치와 환경을 발화마다 기록합니다.

## 2. 스크립트 문장 목록 (작성 필요)

아직 없습니다. 만들 때의 기준:

- 한국어 화자가 자주 어려워하는 대립을 한 번 이상 포함: r/l (right/light), f/p (fan/pan), v/b (very/berry), θ·ð (think, this), z/dʒ (zero, zoo), i:/ɪ (sheep/ship), 어말 자음과 모음 삽입 (bus, milk), 자음군 (street, spring), 단어 강세 (hotel, photograph/photography), 문장 억양 (평서문·의문문).
- 앱 시나리오(`content/scenarios/`)에 나오는 실제 문장 일부 포함.
- 한 문장 3~15단어, 전 화자 공통. 원어민 검수 후 `prompt_id`를 붙여 목록 버전을 고정합니다.
- 각 단어의 기준 발음(ARPAbet)은 라이선스를 확인한 발음 사전에서 가져와 `reference_words`에 넣습니다. espeak-ng·phonemizer는 GPL-3.0이므로 결정 전에는 쓰지 않습니다(`docs/pronunciation.md` §6).

## 3. 녹음 절차

1. 동의서(§6)를 설명하고 서명을 받습니다. 필수 항목(내부 평가)에 동의하지 않으면 녹음하지 않습니다.
2. 조용한 방에서 녹음합니다. 입과 마이크 거리 20~40 cm. 한 문장마다 따로 파일로 저장하고, 잘못 읽으면 다시 읽게 합니다(다시 읽은 것만 보관).
3. 저장 형식: 원본은 그대로 `data/korean_set/raw/`에, 평가용은 16 kHz 모노 PCM16 WAV로 변환해 `data/korean_set/audio/<speaker_id>/<utt_id>.wav`에 둡니다. 변환은 제대로 된 리샘플러를 씁니다(예: `ffmpeg -i in.wav -ac 1 -ar 16000 -af aresample=resampler=soxr -c:a pcm_s16le out.wav`).
4. 품질 확인: 클리핑(최고점 -1 dBFS 이상)이나 심한 잡음이 있으면 다시 녹음하거나 `excluded`에 이유를 적습니다. 실패한 녹음을 학습자 실력 문제로 기록하지 않습니다.
5. 파일마다 SHA-256을 매니페스트에 적습니다.

보관 규칙:

- `data/`는 git에 올리지 않습니다. 클라우드 동기화 폴더(iCloud "데스크탑 및 문서" 포함)에 두지 않고, 디스크 암호화(FileVault)를 켠 컴퓨터에만 둡니다. 저장소 위치가 동기화 대상인지 수집 전에 확인하세요.
- 서명한 동의서와 "화자 ID ↔ 실명" 대응표는 매니페스트와 다른 곳(잠긴 폴더나 종이)에 보관합니다. 매니페스트와 평가 파일에는 이름·연락처를 적지 않습니다.
- 로그, 리포트, 이슈, 채팅에 음성·전사·화자 정보를 붙이지 않습니다(PROTOCOL §2 로그 정책과 같음).
- 동의 철회 시: 해당 화자의 음성, 평가, 매니페스트 항목을 지우고 다음 데이터셋 버전에서 뺍니다. 이미 커밋한 집계 리포트는 다음 버전에서 다시 계산합니다.

## 4. 평가 가이드 (guide_version `rg-1`)

speechocean762와 같은 척도를 씁니다. 그래야 두 데이터셋의 결과를 같은 하네스(`run_eval.py`)로 비교할 수 있습니다.

**1단계 — 전사 확인 (자유 발화만).** 평가자 2명이 음성 인식 결과를 들으면서 고쳐, 실제로 말한 단어를 확정합니다. 둘이 다르면 함께 들어 합의합니다. 합의한 전사가 `reference_text`가 됩니다. 문법 오류는 고치지 않고 들린 대로 적습니다.

**2단계 — 음소 점수 (각 기준 음소마다).**

| 점수 | 뜻 | 예 |
|---|---|---|
| 2 | 맞게 발음함 | |
| 1 | 맞는 소리로 들리지만 억양(악센트)이 강함 | "very"의 v가 v로는 들리지만 약하게 b 쪽으로 기움 |
| 0 | 다른 소리로 들리거나 빠짐 | "very"를 "berry"로, "milk"의 k 탈락 |

점수 0이면 대신 들린 소리를 `heard`에 적습니다(ARPAbet, 빠졌으면 `<del>`, 알 수 없으면 `<unk>`). 기준에 없는 소리가 끼어들면(예: "bus" 끝의 모음 삽입) `inserted`에 적습니다.

**3단계 — 단어 점수.**

- 정확도 0~10: 10 완벽 / 7~9 대부분 맞지만 악센트가 있음 / 4~6 음소의 30% 미만이 틀림 / 2~3 30% 넘게 틀리거나 다른 단어로 들림 / 1 알아듣기 어려움 / 0 소리 없음.
- 강세 {5, 10}: 10 강세가 맞거나 1음절 단어, 5 강세 위치가 틀림.

**4단계 — 문장 점수.**

- 정확도 0~10: 9~10 뚜렷한 오류 없음 / 7~8 오류가 조금 / 5~6 오류와 악센트가 많지만 뜻은 통함 / 3~4 오류가 심함 / 0~2 한두 단어만 알아들을 수 있음.
- 유창성 0~10: 8~10 막힘 없음 / 6~7 가끔 쉼·반복 / 4~5 쉼·반복이 많음 / 0~3 자주 끊김.
- 운율 0~10: 9~10 억양과 속도가 자연스러움 / 7~8 거의 자연스러움 / 5~6 속도가 불안정하고 리듬감이 부족 / 3~4 너무 빠르거나 느리고 리듬이 없음 / 0~2 억양이 매우 어색하고 문장을 끝까지 읽지 못함.
- 완성도 0~1: 기준 단어 중 알아들을 수 있게 말한 비율.

**원칙**

- 억양(미국식·영국식 등)이 다르다는 이유만으로 감점하지 않습니다. 알아듣기 쉬운지와 뜻이 바뀌는지를 봅니다.
- 평가자는 서로의 점수와 앱·모델의 출력을 보지 않습니다. 발화 순서는 평가자마다 무작위로 섞습니다.
- 평가 전 보정 세션: 가이드를 함께 읽고, 공개 데이터 speechocean762(CC BY 4.0)의 발화 20개를 각자 평가한 뒤 공개 점수와 비교해 기준을 맞춥니다. 이 20개는 평가셋에 넣지 않습니다.
- 한 번에 1시간 이하로 평가하고 쉽니다.

## 5. 평가자와 일치도

- 발화마다 평가자 2명 이상(권장 3명). 영어 교육 경험이나 음성학 교육을 받은 사람. 가능하면 한 명은 영어 원어민 또는 그에 가까운 사람.
- 평가자 정보(모국어, 경력, 보정 완료일)는 `raters`에 적습니다. 평가 결과는 평가자별로 `data/korean_set/ratings/<rater_id>.json`(`manifest.schema.json`의 `rating_file`)에 저장합니다.

일치도 계산 (평가가 끝나면 리포트에 모두 적습니다. 기준값을 미리 정하지 않고 측정값을 그대로 보고합니다):

| 수준 | 척도 | 방법 |
|---|---|---|
| 음소 | 0/1/2 순서형 | Krippendorff's α (ordinal, 평가자 3명 이상·결측 허용), 평가자 쌍별 가중 Cohen's κ (quadratic). "틀림(0) 대 나머지" 이진 판정의 쌍별 κ도 함께 |
| 단어 | 정확도 0~10 | ICC(2,1)과 ICC(2,k) (이원 무작위, 절대 일치), 쌍별 Pearson·Spearman. "정확도 ≤ 6" 이진 판정의 쌍별 κ |
| 문장 | 0~10 각 항목 | ICC(2,1), ICC(2,k), 쌍별 Pearson |

- **정답 라벨:** 평가자 평균(음소·단어·문장 모두). 개별 점수도 그대로 보관합니다.
- **사람 상한:** 평가자 한 명과 나머지 평가자 평균의 상관(leave-one-rater-out)을 수준별로 계산합니다. 시스템과 평가자 평균의 상관은 이 값과 나란히 보고합니다. 사람끼리도 일치하지 않는 수준에서 시스템이 더 높을 수는 없습니다.
- **채택 기준 (PA-2/PA-3 제안값):** 이 평가셋에서 음소 수준 상관 ≥ 0.55, 단어 수준 ≥ 0.5를 충족해야 등급 표시를 기본으로 켜는 것을 검토합니다. 충족 전에는 `timing_only`를 유지합니다.

## 7. 하네스 연결 (데이터가 생긴 뒤)

`../so762.py`와 같은 `Utterance`/`Word` 객체를 만드는 `korean_set` 로더를 추가하고, `run_eval.py`에 `--dataset korean` 선택지를 붙입니다. 로더는 평가자 평균을 사람 점수로 쓰고, `unusable`·`excluded` 발화는 뺀 수를 리포트에 적습니다. 결과 리포트는 speechocean762 결과와 나란히 두며, 한국어 악센트 결과를 따로 표시합니다(TRIAGE PA-2). 데이터 없이 로더를 미리 만들지 않았습니다. 형식은 이 문서와 스키마가 기준입니다.
